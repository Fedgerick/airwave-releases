# FedgeOps Airwave downloads

Installer for the FedgeOps Airwave Windows app, which streams your PC's sound to Android phones on your Wi-Fi.

**[Download the latest Windows installer](https://github.com/Fedgerick/airwave-releases/releases/latest/download/FedgeOps-Airwave-Setup.exe)** (Windows 10 or 11)

More information: https://fedgeops.com/airwave/
